# DiagonalNet

> Zero-dependency Deep Learning & Machine Learning Engine built from scratch with pure Go standard library.

---

## ⚡ Overview

**DiagonalNet** is a lightweight, high-performance machine learning suite engineered purely using Go's built-in standard library with **zero external dependencies**.

- 🧠 **Deep Learning Engine**: Analytical backpropagation, custom tensors, matrix math, and optimizers (Adam, SGD).
- 📊 **Tabular & Vision Processing**: Built-in feature scaling, one-hot encoding, tabular profiling, and image transforms.
- 📈 **Native Dashboard & API**: Lightweight HTTP server with live SVG/Canvas visualizer and REST endpoints.
- 🚀 **Concurrency**: Native CPU parallelism via Go goroutines and `sync.WaitGroup`.

---

## 🚀 Quick Start

### Prerequisites
- [Go](https://go.dev/dl/) 1.20+ (optional, for running Go code)
- Git

### Getting Started
```bash
# Clone the repository
git clone https://github.com/itznan/diagonalnet.git
cd diagonalnet

# Update repository
./pull.bat
```
